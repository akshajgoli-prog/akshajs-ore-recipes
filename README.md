# Akshaj's Ore Recipes

A Minecraft datapack that adds custom crafting recipes for overworld ore blocks, allowing you to craft ores directly in survival mode.

## Features
- Custom crafting recipes for overworld ores
- Fully compatible with vanilla Minecraft
- No mods required
- Ideal for survival, skyblock, and limited-resource worlds

## Included Ores
- Coal Ore
- Copper Ore
- Iron Ore
- Gold Ore
- Redstone Ore
- Lapis Lazuli Ore
- Diamond Ore
- Emerald Ore

## Coming Soon
- Nether Gold Ore
- Nether Quartz Ore
- Additional Nether ore recipes

## Installation
1. Download the latest release.
2. Place the `.zip` file in your world's `datapacks` folder.
3. Run `/reload` or restart your world.
4. Enjoy crafting ores!

## Compatibility
- Minecraft Java Edition
- Compatible with datapack-supported versions
